# Salure Nails Design

Site institucional da Salure Nails Design — nail designer em São Paulo/SP.

Página única em HTML, CSS e JS puros (sem build step, sem dependências). Para rodar localmente, basta abrir `index.html` no navegador ou servir a pasta com qualquer servidor estático:

```bash
python -m http.server 8080
```

## Estrutura

- `index.html` — página completa (marcação, estilos e scripts)
- `assets/logo.png` — logotipo
- `assets/anna-sallety.jpg` — foto da profissional
- `assets/portfolio/` — fotos dos trabalhos realizados
